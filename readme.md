# Запуск
* ```make generate```: генерация pb.
* ```make migrate```: миграции БД.
* ```make reset-migrations```: откат миграций БД.
* У вышеперечисленных команд есть версии с префиксом ```fast-``` без перетягивания зависимостей.
# Метрики
## Технические метрики
* ```handled_requests_count```, ```handled_requests_bucket```, ```handled_requests_sum```: \
  кол-во обработанных запросов с разбиением на бакеты по времени ответа и с разбиением по методу и статусу.
## Бизнес-метрики
* ```pvzs_created_counter```: количество ПЗВ с разбиением по городам.
* ```products_created_counter```: количество товаров с разбиением по типу.
* ```receptions_created_counter```: количество приёмок с разбиением по ПВЗ.

# Вопросы и решения:

## 1. API
* API реализован в качестве grpc-контракта, но http-gateway соответствует контракту из задачи.
* Статус приёмки ```close``` заменен на ```closed``` из предположения, что была сделана опечатка.
* Grpc: enum ```ReceptionStatus``` был упразднён и заменён на ```string``` из-за проблем с маппингом в json.
