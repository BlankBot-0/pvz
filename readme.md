# Вопросы и решения:

## 1. API

* Убраны поля ```id``` и ```registrationDate``` из запроса для создания нового ПВЗ по аналогии с созданием новой приёмки.
  * UPD: Эти опциональные поля добавлены обратно, чтобы была возможность шардирования БД по идентификаторам ПВЗ.
* Статус приёмки ```close``` заменен на ```closed``` из предположения, что была сделана опечатка.
* Grpc: enum ```ReceptionStatus``` был упразднён и заменён на ```string``` из-за проблем с маппингом в json.

## 2. Приёмка товаров

* В случае, когда сотрудник пытается закрыть приёмку без добавленных товаров, принято решение удалять запись о приёмке, чтобы не засорять базу.
